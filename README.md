# Schematica

Schematica is a Minecraft mod designed to save, create, and place schematics across worlds. It provides tools for saving and loading schematics, placing them in the world, and moving or rotating them as needed. This mod is compatible with Minecraft 1.21.11 and Forge.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Forge profile.

## Use

1. **Save a Schematic:**
   - Use the command `/schematic save <name>` to save the schematic at your current position.

2. **Load a Schematic:**
   - Use the command `/schematic load <name>` to load a saved schematic.

3. **Place a Schematic:**
   - Use the command `/schematic place <name>` to place the loaded schematic at your current position.
